# BeatForge — 16-Step Procedural Drum Sequencer

Procedural 16-step rhythmic drum sequencer powered by Web Audio API synthesizing Kick, Snare, Hi-Hat, and Claps.

> Engineered with precision by **Sabhyam Trivedy** (Founder & Software Engineer).  
> Part of the open-source developer tools suite.

---

## ⚡ Live Demo
Experience the application directly in your browser:  
🔗 **[Launch Web App](https://sabhyamtrivedycoder.github.io/web-drum-machine/)**

---

## 🛠️ Tech Stack & Features
- **Frontend**: Zero-dependency vanilla HTML5, CSS3, ES6+ JavaScript.
- **Design System**: Glassmorphism dark mode with Inter and JetBrains Mono typography.
- **Testing**: Automated unit tests executable via Node.js (`test.js`).
- **Hosting**: Deployed with zero build steps on GitHub Pages.

---

## 🧪 Run Tests Locally
```bash
node test.js
```
